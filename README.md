# 🛒 Checkout Systemm

Checkout system built with **Java**, applying **advanced Object-Oriented Programming (OOP) concepts**. The project simulates an online store's order flow, with stock control, discount coupons, and order status tracking.

---

## ⚡ Key Features

- 📦 **Product management:** register products with name, price, and stock.
- 🛍️ **Order creation:** build orders with multiple items per customer.
- 🎟️ **Discount coupon:** apply discount codes to the order total.
- 🔄 **Order status tracking:** PENDING, PAID, SHIPPED, or CANCELLED, with cancellation only allowed before shipping.
- 📃 **Full listing:** view all products, orders, and their current status.

💡 Possible improvement: custom exceptions, database persistence, and status notifications, bringing the project closer to a real e-commerce application.

---

## 🛠 Technologies Used

- **Language:** Java
- **Paradigm:** Object-Oriented Programming (OOP)
- **Execution:** Console application (CLI)

💡 Possible improvement: turn it into a REST API with Spring Boot, reusing the JWT authentication concepts from the library management project.
